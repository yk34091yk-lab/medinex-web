# 🏥 MediNex

### Digital Patient Case-Taking & Clinical Documentation System

MediNex is a web-based healthcare application designed to **digitize and simplify patient case-taking**. It provides a structured platform for recording patient information, symptoms, medical history, and clinical notes, helping doctors and medical staff manage case information more efficiently.

---

## ✨ Features

* 👤 Digital Patient Registration
* 📝 Structured Patient Case-Taking
* 👨‍⚕️ Doctor Dashboard
* 🛡️ Admin Dashboard
* 🚨 Red Flag / Alert System
* 📋 Digital Medical Records
* 🔐 Role-Based Access
* 📊 Organized Patient Information

---

## 💻 Installation

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/medinex.git
cd medinex
```

### Backend Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install fastapi uvicorn pymongo
```

Run the FastAPI server:

```bash
uvicorn main:app --reload
```

---

## 🌐 Deployment

The **frontend** can be hosted using GitHub Pages.

The **FastAPI backend** and **MongoDB database** need to be deployed separately on appropriate hosting services.
